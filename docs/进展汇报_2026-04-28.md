## 一、项目三条线总览

### 背景说明

本项目分三条并行推进的工作线：

- **第一条：规则代码模块化**（C++→C 转换），目标是把原始 C++ 规划控制算法逐函数转换为符合 GAASD 规范的 C 语言，最终扫描进 GAASD 组件库
- **第二条：ACC 新功能模块**，在 GAASD 平台上从零搭建符合规范的 ACC（自适应巡航控制）算法模块，包含函数实现、注释规范、仿真工程验证
- **第三条：CARLA 仿真联调**，搭建 CARLA 仿真环境与 GAASD 算法之间的 Bridge，实现闭环仿真测试，最终让 GAASD 算法能在 CARLA 里跑通 ACC 闭环

## 四、CARLA 仿真联调进展

### 1. 整体架构

搭建了一套 Python Bridge（`carla_bridge.py`），连接 CARLA 0.9.15 与 GAASD 算法，通过 **ZMQ PUB/SUB + JSON** 协议传输数据，实现 CARLA 仿真环境与算法的双向通信。

```
CARLA
  ↓ carla_bridge.py（ZMQ PUB 5701）
GAASD 算法组件
  ↓（ZMQ SUB 5702）
carla_bridge.py
  ↓
CARLA ego 车辆控制
```

协议文档：`docs/carla_gaasd_bridge_protocol.md` **v0.3.0**（6 个 PUB topic + 1 个 SUB topic，含完整坐标系转换公式）

### 4. 阶段一测试结论（2026-04-28 完成）

**测试环境：** CARLA 0.9.15，Town10HD_Opt 地图，同步模式 20Hz，Python 3.8

**测试链路：** `CARLA → carla_bridge.py → acc-runner.py → carla_bridge.py → CARLA ego 车辆`

| 验收项 | 结果 | 说明 |
|---|---|---|
| CARLA 连接 | ✅ 通过 | health-carla.sh 返回 healthy |
| Bridge 数据发布 | ✅ 通过 | ego_state、lead_vehicle、chassis_feedback 全部正常 |
| 前车识别 | ✅ 通过 | valid=true，clearance_m=30.705m，selection_rule=same_lane_nearest_front |
| ACC 控制输出 | ✅ 通过 | 20 秒 401 条控制命令全部被 Bridge 接收（完整闭环）|
| 车辆速度响应 | ✅ 通过 | ego 速度从 0 加速到 3.66 m/s，throttle=0.201 |

| 超时安全制动 | ✅ 通过 | Runner 停止后 7 秒，Bridge 主动下发 brake=1.0，throttle=0.0 |

**结论：** 阶段一最小闭环已跑通。算法链路和 Bridge 协议可行，证据充分，可以进入阶段二。

### 5. 本轮修复的关键问题

**同步模式仿真跑太快：** 原先 Bridge 无限 tick，仿真时间远快于真实时间，ACC Runner 实际 20Hz 发命令跟不上。修复：启用 `realtime_pacing`，每轮 tick 后按 `fixed_delta_seconds=0.05` 补 sleep。

**前车生成位置不稳定：** 按 CARLA `waypoint.next(distance)` 生成前车，曾出现前车落到 ego 侧向 19m 处，导致 `lead_vehicle.valid=false`。修复：默认改用 `ego_forward` 直接沿 ego 当前朝向放置前车。

**控制超时后保留 throttle：** Runner 停止后 CARLA 仍保留最后一次 throttle。修复：超过 `timeout_sec` 后 Bridge 主动下发 `throttle=0, brake=1, steer=0`。

```
开发 libcarla_gaasd_adapter.so（C++ 封装 ZMQ/JSON，暴露 C ABI）
```

**硬性前置条件（进入阶段二前必须确认）：**

> ⚠️ GAASD `run_simulation.sh` 在 Docker 容器 `ubuntu:env` 内编译并运行仿真。`libcarla_gaasd_adapter.so` 在容器内被加载，因此：
> 1. 需确认 ZMQ 在 `ubuntu:env` 内可用（`docker run --rm ubuntu:env ldconfig -p | grep zmq`）
> 2. 适配库必须在与 `ubuntu:env` 相同 ABI 环境中编译，不能直接在宿主机编译后放入
