# ACC / LKS 模块别名中文对照表

## 1. 修改边界

本次修改内部计算节点和复合组件内部输入/输出边界块的
`project_component.alias`，用于改善画布显示。

- 不修改组件英文名称 `name`。
- `input`、`output` 边界块仅修改模块别名，不修改其实际接口名和小驼峰端口名。
- 不修改 `channel_input`、`channel_output` 的别名及外部通信字段。
- 不修改局部/全局参数名、状态名、`operateKeys` 和常量实际符号。
- 不修改官方基础组件的 `properties.alias`，继续保留“输入”“输出”“乘法运算”“读取全局参数”等官方名称。
- 不修改 Pangu 应用、进程、模块和外部通信通道标识。
- 已经是中文的复合子系统别名保持不变。

## 5. 明确保留的英文标识

下列内容属于接口或运行结构，不纳入本次中文模块别名迁移：

- ACC、LKS 复合组件的实际输入输出端口名，例如 `egoSpeedMps`、`leadDistanceM`、`c0`、`steerRad`；对应边界块仅显示中文模块别名。
- 外部通道及通道字段，例如 `acc_input`、`lks_input`、`target_accel_mps2`、`steer_rad`。
- 局部/全局参数和状态实际键名，例如 `param_.distanceErrorGainPerS`、`global::params.lks_vMin`。
- 常量实际符号，例如 `COMMAND_BRAKE`、`MINIMUM_SPEED_SQUARED_M2PS2`；仅画布块的模块别名显示为中文。
- Pangu 应用和进程技术标识，例如 `accApplication`、`lksApplication`、`lksProcess`。
