# CARLA ACC 最小组件 C++ 规范校验报告

## 校验依据

- 规范文件：`docs/C++代码规范.docx`
- 规范版本：`v1.0.33`
- 校验日期：2026-06-12
- 校验范围：本目录下 `include/`、`src/` 和 `CMakeLists.txt`

## 结论

本目录中的六个组件已改为 GAASD `FuncModule<Traits>` 结构化组件，并通过
GCC 9.4 C++20 自包含编译。组件源码不直接访问 CARLA、ZMQ、JSON 或 adapter，
运行时通信由组件目录外的边界绑定层完成。

## 规则检查

| 规则类别 | 检查结果 |
|---|---|
| ENG-001～ENG-006 | 目录由 `include/`、`src/`、`CMakeLists.txt` 组成；模块继承 `FuncModule<Traits>` |
| INC-001 | 每个 `.cpp` 只包含自身对应的 `.hpp` |
| TYPE-001～TYPE-015 | 每个 Traits 均定义 `Input/Output/Param/State/Sub`；端口不含指针和第三方类型 |
| CTOR-003 | 无子模块组件统一使用 `using FuncModule::FuncModule` |
| RUN-001～RUN-011 | 每个 `.cpp` 仅定义一个固定签名的 `run(const Input&, Output&)` |
| BODY-006 | `run()` 内不声明或传递裸指针 |
| BODY-023～BODY-029 | `run()` 内无外部函数、网络、文件、线程或 C ABI 调用 |
| BODY-030～BODY-047 | 仅使用基础运算、命名条件变量、`if/else` 和 `std::clamp` |
| BODY-057～BODY-068 | 所有结果均显式写入 `output`，无隐藏全局状态 |
| CMT-034～CMT-036 | 函数体语义块和输出赋值均使用 `/** @brief ... */` 注释 |
| DEP-004～DEP-008 | 组件仅依赖 C++ 标准库及本目录 `FuncModule.hpp` |

## 编译验证

```bash
cmake -S generated/gaasd_p0_acc_min_components_src \
  -B /tmp/gaasd_p0_acc_min_components_v1033_build \
  -DCMAKE_BUILD_TYPE=Release
cmake --build /tmp/gaasd_p0_acc_min_components_v1033_build -j2
```

构建启用了 `-Wall -Wextra -Wpedantic -Werror`，当前编译无警告、无错误。

## 边界说明

`tools/carla_bridge/adapter/src/carla_gaasd_adapter.cpp` 是 ZMQ/JSON 运行时适配库，
不是 GAASD 扫描组件，因此不适用本规范对组件 `run()` 的白名单限制。若把
adapter 调用重新放入组件 `run()`，将再次违反 `BODY-006`、`BODY-023～029`
和 `DEP-004～008`。
